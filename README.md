## الخوارزمية الجينية (Genetic Algorithm) مع مشغلات مخصصة – Custom Operators 🧬


هذا المشروع يستعرض كيفية استخدام الخوارزميات الجينية (Genetic Algorithms) لحل مسائل تحسين (Optimization Problems) باستخدام مكتبة scikit-opt
.
كما يوضح كيفية تخصيص مشغلات الخوارزمية (Operators) مثل الاختيار (Selection)، التصنيف (Ranking)، العبور (Crossover)، و الطفرة (Mutation).

## 🚀 الفكرة الأساسية

الخوارزمية الجينية مستوحاة من الانتخاب الطبيعي حيث يتم تحسين الحلول بشكل تدريجي عبر أجيال متتالية حتى الوصول إلى أفضل حل ممكن.

في هذا المثال، نحاول تقليل دالة هدف بسيطة:

f(x)=x02​+(x1​−0.05)2+(x2​−0.5)2

## 🛠️ المزايا

استخدام مكتبة scikit-opt لتبسيط بناء الخوارزمية.

تعريف Selection Operator مخصص (Tournament Selection).

تسجيل مشغلات متعددة (Ranking, Crossover, Mutation).

تطبيق عملي سهل وواضح لفهم أساسيات الخوارزميات التطورية.
